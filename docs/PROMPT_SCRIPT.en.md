## 4. Pitfalls (learned)
- Import map addresses must start with `./`, `/` or `../` (bare `vendor/...` is silently null).
- OrbitControls (ES) imports bare `three` -> needs an import map.
- JS `Float32Array` grids: send float32-rounded values (9 sig. digits), rebuild with `Float32Array.from`.
- LCG noise in JS uses double rounding: `int(float(seed)*1103515245.0+12345.0) & 0x7fffffff`. Port mulberry32 with int32 ops.
- Python `value or 1e-12` differs from JS for NaN.
- Font subset must include glyphs of BOTH UIs + all payload text (else silent fallback).
- PowerShell variables are case-insensitive (`$cw` overwrote `$CW`). `.ps1` with Korean needs UTF-8 BOM. `Start-Process` ignores `Set-Location` (pass `-WorkingDirectory`).
- Hidden browser pane throttles `requestAnimationFrame`; drive state via exposed `__plat3` API instead of waiting.
- Opening `file://` in the agent browser is blocked; test exports by serving a temp copy, then delete it.
- Original has wall-clock animations (AMR packets): compare WebGL only against its own self-diff baseline.
- `.bat` must be CRLF; leftover `uvicorn --reload` child processes keep port 8000.
